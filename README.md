# Vote for KraftInk

Connect server voting sites, verify votes and reward players. The public Vote page lists your voting sites and shows a leaderboard.

Install Vote from **Plugins** in the KraftInk admin panel, then open **Extensions → Vote** to configure voting sites and rewards.
